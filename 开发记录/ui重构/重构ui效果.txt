下面这套方案的核心思路是：**保留你现有的所有 HTML 结构和 class 名不变**，只重新设计一套"清新治愈系"的视觉语言去覆盖它——毕竟应用图标是 🌱（豆豆/嫩芽），所以配色我用了**鼠尾草绿 + 温暖杏橙**这一组互补但都很柔和的色系，替换掉之前深色科技感的黑底霓虹光晕，改成浅色纸感背景 + 大量留白 + 柔和投影，视觉上会安静很多。

因为你之前的代码里绝大部分颜色都是用 `var(--xxx)` 引用的，所以**改一份 CSS 变量表，全站的颜色基本就自动换血了**，我在此基础上再补几处"硬编码的深色阴影/发光效果"改成柔和阴影，以及把直角边框改成更圆润的卡片感，整体质感就会从"科技控制台"变成"清新笔记本"的感觉。

## 一、设计基调说明

| 维度 | 原来（深色科技风） | 现在（清新治愈风） |
|---|---|---|
| 背景 | 纯黑 + 霓虹光晕 | 米白/浅豆绿纸感 + 柔焦色块 |
| 主色 | 荧光绿 `#10b981` | 鼠尾草绿 `#5FAE79`（更哑光柔和） |
| 任务模式色 | 靛蓝紫 `#6366f1` | 温暖杏橙 `#F2A65A`（互补但不刺眼） |
| 边框 | 清晰灰线条 | 极淡边线，主要靠阴影表现层次 |
| 圆角 | 8-12px | 14-20px，更饱满圆润 |
| 阴影 | 深黑高对比 | 带绿色调的浅色柔影 |

## 二、设计令牌（Design Tokens）—— 最关键的一步

把这段直接替换掉原来 `:root` 里的变量定义，**80% 的视觉效果会立刻切换过来**，因为原来几乎所有组件都在引用这些变量：

```css
:root {
  /* 背景层级：不用纯白，用带一点点绿调的米白，长时间看更不累眼 */
  --bg-primary: #F7F9F4;
  --bg-secondary: #FFFFFF;
  --bg-tertiary: #F0F4EC;

  /* 边框极淡化，让"分隔"主要靠留白和阴影完成，而不是硬线条 */
  --border-color: #E5EAE0;

  /* 文字用温暖的深灰绿，而不是纯黑，阅读起来更柔和 */
  --text-primary: #33403A;
  --text-secondary: #7C8A80;
  --text-muted: #ABB6AD;

  /* 主色：鼠尾草绿（呼应 🌱 图标），哑光不刺眼 */
  --primary-color: #5FAE79;
  --primary-light: #8FCE9E;
  --primary-dim: rgba(95, 174, 121, 0.12);

  /* 任务模式色：温暖杏橙，与绿色形成舒服的互补对比，但饱和度收得比较低 */
  --task-color: #F2A65A;
  --task-light: #F7C489;
  --task-dim: rgba(242, 166, 90, 0.14);

  --warn-color: #E8B84B;
  --danger-color: #E8735C;

  /* 新增：柔和阴影系统，带一点绿色调而不是纯黑，营造"漂浮在纸面上"的感觉 */
  --shadow-sm: 0 2px 8px rgba(76, 98, 78, 0.06);
  --shadow-md: 0 6px 20px rgba(76, 98, 78, 0.09);
  --shadow-lg: 0 14px 36px rgba(76, 98, 78, 0.14);

  /* 新增：圆角比例尺，统一管理，让整站圆角风格一致 */
  --radius-sm: 10px;
  --radius-md: 16px;
  --radius-lg: 22px;
  --radius-pill: 999px;
}

body {
  background: var(--bg-primary);
  color: var(--text-primary);
}
```

## 三、背景装饰：把"霓虹光晕"换成"柔焦色块"

原来的 `.glow-effect` 是深色背景下的高饱和霓虹光斑，现在改成浅色背景下低饱和度的大色块虚化，效果更像水彩晕染而不是赛博朋克：

```css
.glow-effect {
  position: fixed;
  border-radius: 50%;
  filter: blur(120px);
  opacity: 0.35;         /* 从深色主题的 .12 提高到 .35，因为浅色背景需要更明显才能看出层次 */
  pointer-events: none;
  z-index: 0;
}
.glow-effect-1 { width: 420px; height: 420px; background: #B7E4C7; top: -120px; left: -100px; }
.glow-effect-2 { width: 380px; height: 380px; background: #FFE1B8; bottom: -120px; right: -60px; }
.glow-effect-3 { width: 320px; height: 320px; background: #D8F0DB; top: 45%; right: 15%; }
```

## 十、细节收尾：滚动条 & 弹窗阴影也要柔化

深色主题下弹窗常用 `rgba(0,0,0,.4~.5)` 的重阴影，浅色主题里这种黑影会显得很突兀（像贴了一块脏东西），统一换成前面定义的绿调阴影：

```css
/* 全局滚动条，浅色主题下细一点、颜色淡一点更精致 */
::-webkit-scrollbar { width: 6px; height: 6px; }
::-webkit-scrollbar-thumb {
  background: #D3DED2;
  border-radius: 999px;
}
::-webkit-scrollbar-thumb:hover { background: #B8C7B5; }

/* 所有弹出层（下拉菜单/抽屉/工作区菜单）统一用柔和阴影 */
.dropdown-menu,
.tm-agent-drawer,
.tm-workspace-menu {
  box-shadow: var(--shadow-lg);
  border: 1px solid var(--border-color);
}

/* 确认弹窗遮罩层也调淡，避免浅色页面突然被深黑蒙层压暗，割裂感太强 */
.confirm-dialog-overlay,
.modal-overlay {
  background: rgba(51, 64, 58, 0.35);   /* 用主文字色的低透明度，而不是纯黑 */
  backdrop-filter: blur(3px);
}
.confirm-dialog,
.modal-content {
  background: var(--bg-secondary);
  border-radius: var(--radius-lg);
  box-shadow: var(--shadow-lg);
}
```
